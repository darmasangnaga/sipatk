# SIPATK
Sistem Informasi Pengelolaan Anggaran dan Transaksi Keuangan.

## Deskripsi
SIPATK adalah aplikasi berbasis web yang dirancang untuk membantu
pengelolaan anggaran dan pencatatan transaksi keuangan pada suatu instansi.
Sistem ini dibuat untuk mendukung transparansi dan pengelolaan data keuangan
secara terstruktur.

Project ini dikembangkan sebagai bagian dari tugas mata kuliah
**Teknologi Open Source**.

## Fitur Utama
- Manajemen data instansi
- Pengelolaan transaksi keuangan
- Hak akses pengguna
- Laporan data keuangan

## Teknologi yang Digunakan
- PHP
- MySQL
- HTML, CSS, JavaScript
- Bootstrap

## Instalasi
1. Clone atau download repository ini
2. Extract project ke direktori web server (contoh: `htdocs`)
3. Import database (jika tersedia)
4. Jalankan aplikasi melalui browser

## Assets
Folder assets disediakan dalam bentuk file **assets.zip** untuk menghindari
keterbatasan upload file di GitHub.

Langkah penggunaan assets:
1. Extract file `assets.zip`
2. Pastikan folder `assets` berada satu level dengan file `index.php`
