# SIPATK
Sistem Informasi Pengelolaan Anggaran dan Transaksi Keuangan

## Deskripsi
SIPATK adalah aplikasi berbasis web yang digunakan untuk membantu pengelolaan
anggaran dan transaksi keuangan pada suatu instansi.

Project ini dibuat sebagai bagian dari tugas perkuliahan dan dipublikasikan
sebagai open source untuk tujuan pembelajaran.

## Teknologi
- PHP
- MySQL
- HTML, CSS, JavaScript
- Bootstrap

## Instalasi
1. Clone atau download repository ini
2. Extract folder project ke direktori web server (htdocs)
3. Import database (jika disediakan)
4. Jalankan melalui browser

## Assets
Folder assets disediakan dalam bentuk file **assets.zip** untuk menghindari
keterbatasan upload file di GitHub.

Langkah penggunaan:
1. Extract `assets.zip`
2. Pastikan folder `assets` berada satu level dengan `index.php`

## Catatan
Project ini dibuat untuk keperluan tugas kuliah.
